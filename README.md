# IRAQ DARK 🇮🇶

مساحة داكنة للنقاش العراقي — منتدى متكامل بواجهة عربية (RTL) وخلفية Node.js + SQLite.

![stack](https://img.shields.io/badge/stack-Vite%20·%20Express%20·%20SQLite-0b0b0c?style=flat-square&labelColor=c9a66b&color=c9a66b)

## المميزات

**الواجهة**
- واجهة داكنة متجاوبة (RTL) مع علم العراق المتحرك وخط Tajawal
- توجيه كامل عبر `#/` (الرئيسية / المواضيع / الموضوع / الأقسام / الملف الشخصي / الإشعارات / المحفوظات)
- بحث فوري في المواضيع + فلترة بالأقسام + ترتيب (الأحدث / الأكثر نقاشاً / الأكثر إعجاباً) + ترقيم صفحات
- إشعارات فورية بعدد غير المقروء في الشريط العلوي
- تنبيهات Toast، حالات تحميل وفراغ، وقائمة جوال (Hamburger)

**المنصة**
- تسجيل / دخول / خروج بجلسات محفوظة في قاعدة البيانات (7 أيام)
- مواضيع + ردود + تعديل وحذف (للمالك أو المدير)
- إعجاب بالموضوعات والردود، وحفظ (Bookmarks)
- متابعة الأعضاء + عدّاد المتابعين + نبذة (Bio) في الملف الشخصي
- إشعارات: متابعة، رد، إعجاب
- عدّاد مشاهادات ( مرة واحدة لكل زائر كل 24 ساعة)

**الخادم**
- Express 5 + better-sqlite3 (WAL) مع ترحيل تلقائي للـ schema عند الإقلاع
- حماية: عناوين أمان، تحديد محاولات الدخول (rate limit)، حجم جسم الطلب، جلسات `httpOnly`
- يقدّم النسخة المبنية (`dist/`) والـ API من نفس المنفذ في الإنتاج

## التشغيل

```bash
npm install

# وضع التطوير (واجهة على :3000 + API على :4000 مع proxy)
npm run api        # في نافذة
npm run dev        # في نافذة أخرى

# الإنتاج (كل شيء على :4000)
npm run build
npm start
```

متغيّرات البيئة (اختيارية):

| المتغيّر | الوصف | الافتراضي |
| --- | --- | --- |
| `PORT` | منفذ الخادم | `4000` |
| `HOST` | عنوان الاستماع | `0.0.0.0` |
| `ALLOWED_ORIGINS` | مصادر CORS مفصولة بفواصل (إن كان الواجهة على نطاق آخر) | فارغ (نفس النطاق) |
| `TRUST_PROXY` | `1` عند العمل خلف بروكسي/نفق | غير مفعّل |

## بنية المشروع

```
├── index.html            # نقطة الدخول (RTL, ar)
├── vite.config.js        # إعداد Vite + proxy للـ API
├── src/
│   ├── main.js           # التطبيق كله: router + views + api
│   └── style.css         # نظام التصميم الداكن
├── server/
│   ├── server.cjs        # API + تقديم dist
│   ├── start.cjs         # نقطة تشغيل الإنتاج
│   ├── init-db.cjs       # تهيئة القاعدة
│   └── upgrade-db.cjs    # جداول الميزات المتقدمة
└── data/                 # قاعدة البيانات (غير مرفوعة للـ git)
```

## أهم مسارات الـ API

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `POST` | `/api/auth/register` | إنشاء حساب |
| `POST` | `/api/auth/login` | دخول |
| `GET` | `/api/auth/me` | المستخدم الحالي |
| `GET` | `/api/topics?q=&category=&sort=&page=` | قائمة المواضيع (بحث/فلترة/ترقيم) |
| `POST` | `/api/topics` | إنشاء موضوع |
| `GET` | `/api/topics/:id` | موضوع + ردوده |
| `POST` | `/api/topics/:id/like` | إعجاب/إزالة |
| `POST` | `/api/topics/:id/bookmark` | حفظ/إزالة |
| `POST` | `/api/topics/:id/replies` | إضافة رد |
| `GET` | `/api/users/:id/profile` | ملف المستخدم |
| `POST` | `/api/users/:id/follow` | متابعة/إلغاء |
| `GET` | `/api/notifications` | الإشعارات |
| `GET` | `/api/stats` | إحصاءات المنصة |
